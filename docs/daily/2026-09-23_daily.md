## Zusammenfassung

Nach dem initialen Commit wurden drei kleine Verbesserungen am alten
Frontend umgesetzt. Danach folgte der komplette Umbau in neun Etappen: das
Flask-Backend wurde in eine Onion-Architektur (Domain, Application,
Infrastructure, API) mit FastAPI überführt, eine neue API v2 eingeführt und
das alte Single-File-Frontend durch eine React/TypeScript-Anwendung ersetzt.
Am Ende des Tages waren Legacy-API und altes Frontend entfernt; das Verhalten
beim Schreiben der Backlog-Dateien ist per Golden-Files abgesichert. Dabei
wurden drei vorhandene Fehler behoben.
