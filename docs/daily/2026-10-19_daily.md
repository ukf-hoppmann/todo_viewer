# Tagesbericht 2026-10-19

## Zusammenfassung

Der Neubau ist jetzt unter Port 5411 erreichbar, weil der Harness dort sucht; der alte Viewer ist auf Port 5412 gewandert. Host- und Container-Port sind gleich (Neubau 5411, alt 5412; `VIEWER_PORT`, `PORT`, `HEALTHCHECK`, Standard in `settings.py`). Das Image des Neubaus wurde neu gebaut, vorher gab es ein Backup der `viewer.db` (`integrity_check` ok); der alte Viewer wurde nicht neu gebaut. Der Container `todo-viewer-next` wurde neu angelegt und antwortet auf Port 5411. Der Harness spricht weiter `/api/v2`, das der Neubau nicht kennt (404); bis zur Umstellung auf die neue API oder MCP erreicht er auf 5411 also keine Backlog-API. Der alte Viewer lief zum Zeitpunkt nicht.

Danach wurde die Projektleiste schlanker. Bearbeitet wird über einen Stift im Kopf oder per Doppelklick. Die Sync-Warnung öffnet den Abgleich direkt, und ↻ erscheint nur beim Hovern. Alles Fällige meldet sich jetzt über eine Glocke, global und je Projekt: Wecker und fällige Notes stehen in einer Liste, der zuletzt fällig gewordene Eintrag oben und aufgeklappt. `⏰n` und `!n` sind aus der App-Leiste verschwunden. Der Server liefert dafür `due_since` für fällige Notes. Gemergt ist das in `main`, im laufenden Container aber noch nicht.
