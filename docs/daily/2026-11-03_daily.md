# Tagesbericht 2026-11-03

## Zusammenfassung

Der Sync-Dialog erklärt Konflikte jetzt: Er zeigt, welche Seite seit dem letzten Abgleich geändert ist, erkennt wahrscheinliche Umbenennungen und gibt eine Empfehlung mit Begründung ab. Entschieden wird weiter je Konflikt, nichts wird vorausgewählt oder automatisch gelöscht. Dazu läuft der Neubau zusätzlich hinter einem nginx-Proxy unter `http://todo.localhost:5413`. Der Container ist nicht neu gebaut, beides wirkt im laufenden Viewer noch nicht. Die Abnahme von STORY-095 steht aus.

Abgeleitet aus Basis-Hash und Abgleichzeit, nichts wird gespeichert. | 536a905, STORY-095 |
