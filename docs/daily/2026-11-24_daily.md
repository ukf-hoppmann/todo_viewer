# Daily Development — 2026-11-24

## Summary

Das Feld Area ist aus Server und Datenbank entfernt (`TASK-071`): kein `area` mehr in Items, HTTP, MCP, Memo-Beförderung und Import, die Index-Zeilen für Agenten haben keine Spalte Area mehr, und eine Migration entfernt die Spalte und die Tabelle der Bereiche, ohne andere Daten zu verlieren. Die Task wartet auf die Abnahme. Außerdem trägt der Mindmap-Spiegel jetzt Zuordnungen, Dokumente, entfernte Platzierungen und den Papierkorb (`TASK-081`); auch diese Task wartet auf die Abnahme. Aus einem Knoten der Mindmap lässt sich jetzt ein Item oder ein Memo anlegen, das gleich am Knoten hängt (`TASK-073`, Server); auch diese Task wartet auf die Abnahme. Die Oberfläche dazu steht jetzt: Im Detail eines Knotens gibt es „Item anlegen“ und „Memo anlegen“ (`TASK-075`); auch sie wartet auf die Abnahme.
