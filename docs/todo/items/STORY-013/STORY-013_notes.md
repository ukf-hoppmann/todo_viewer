# STORY-013 — Items in der UI anlegen

## 2026-09-28 — Umsetzung

### Decided

- Der Anlege-Dialog fragt Typ, Titel, Bereich, Priorität, Ziel, Kriterien und Kurzfassung ab; Abhängigkeiten werden danach im Bearbeiten-Modus gesetzt, damit der Dialog schlank bleibt.
- Ein Kind übernimmt Quelle und Bereich des Parents, bekommt Pflicht für Parent „Ja“ und nur die zum Parent passenden Typen.
- „＋ Neu“ wählt als Projekt das des ausgewählten Items, sonst das erste nutzbare.
