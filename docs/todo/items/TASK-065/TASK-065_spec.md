# TASK-065 — Spec: Markierungen „verworfen“ und „später“

Fachliche Regeln: Abschnitt „Markierung“ in `STORY-100_spec.md`.

## Umfang

- Ein Knoten trägt höchstens eine Markierung (keine, verworfen, später); setzen und löschen über API, MCP und
  Oberfläche.
- Die Markierung gehört nur zum Knoten selbst, nicht zu seinen Items und nicht zu Unterknoten. Sie ändert weder
  Summen noch den abgeleiteten Zustand.
- Markierte Knoten sind sichtbar abgesetzt; der Filter kann sie ausblenden.

## Offen

- Feste Werte oder frei: vor der Umsetzung mit dem Owner klären.
